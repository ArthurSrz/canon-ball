## Directory Purposes

**`backend/`:**
- Purpose: FastAPI REST server, router definitions, configuration
- Contains: Main app, router modules, schemas
- Key files: `backend/main.py` (entry point), `backend/routers/*.py` (endpoints)

**`frontend/src/`:**
- Purpose: React SPA source code
- Contains: App shell, screens, components, hooks, API layer
- Key files: `frontend/src/App.jsx` (root), `frontend/src/api.js` (HTTP layer)

**`frontend/src/screens/`:**
- Purpose: UI components for each of 6 steps
- Contains: One JSX file per step, fully self-contained
- Key files: `SetupScreen.jsx`, `MapScreen.jsx`, `FocalLineScreen.jsx` (main screens)

**`frontend/src/components/`:**
- Purpose: Reusable visualization and UI components
- Contains: UMAP visualization, hero animation, tweaks panel
- Key files: `SemanticMap.jsx` (UMAP viz), `CannonScene.jsx` (loading animation)

**`results/`:**
- Purpose: Persistent experiment outputs
- Contains: JSON files written by backend (experiment data, analysis, chains)
- Generated: `experiment.json` on fire, `analysis.json` after UMAP, chain JSONs after attribution
- Committed: No; generated artifacts only

**`pages/`:**
- Purpose: Legacy Streamlit pages (deprecated, will be removed in refactor)
- Contains: Old UI code for Canon Ball and Borges Graph visualization
- Key files: `pages/1_Canon_Ball.py`, `pages/2_Borges_Graph.py`

## Key File Locations

**Entry Points:**
- `backend/main.py`: FastAPI startup (run with `uvicorn backend.main:app --port 8000`)
- `frontend/src/main.jsx`: React mount point
- `frontend/vite.config.js`: Development server config (port 5173, `/api` proxy)

**Configuration:**
- `backend/config.py`: Unified env var loading (replaces st.secrets)
- `.env`: Not committed; contains OPENROUTER_API_KEY, NEURONPEDIA_API_KEY (see `.env.example`)
- `frontend/vite.config.js`: Proxy `/api` to `http://localhost:8000` during dev

**Core Logic:**
- `canon_experiment.py`: Run trials, embed outputs
- `canon_analysis.py`: UMAP projection, dispersion metrics
- `borges_graph.py`: Build attribution chains (Circuit Tracer integration)
- `neuronpedia_client.py`: NLA + circuit tracer API client

**Testing:**
- No dedicated test suite yet (QA via manual testing and results inspection)

**API Routes:**
- `POST /api/experiment/fire`: Run experiment (async, returns immediately with UMAP results)
- `GET /api/experiment/results`: Fetch cached experiment (after fire completes)
- `POST /api/chain/trace`: Build attribution chain from prompt
- `POST /api/chain/focal`: Build focal line scene (Circuit Tracer + NLA)
- `GET /api/chain/status`: Poll chain computation progress
- `GET /api/chain/results`: Fetch pre-computed chains (from background thread)
- `GET /health`: Check key availability

## Naming Conventions

**Files:**

- **Python modules:** snake_case (e.g., `canon_experiment.py`, `backend/config.py`)
- **React components:** PascalCase (e.g., `CannonScene.jsx`, `SetupScreen.jsx`)
- **Utility/hook files:** camelCase with `use` prefix for hooks (e.g., `useExperiment.js`)
- **Result files:** snake_case descriptive (e.g., `chain_control.json`, `analysis.json`)

**Directories:**

- **Backend:** `backend/routers/`, `backend/__pycache__/`
- **Frontend:** `frontend/src/screens/`, `frontend/src/components/`, `frontend/src/hooks/`
- **Output:** `results/`, `test_screenshots/`
- **Config:** `.env`, `.streamlit/`, `.venv/`

**Classes & Types:**

- **Pydantic models:** PascalCase with `Request` suffix (e.g., `FireRequest`, `TraceRequest`)
- **Data classes:** PascalCase (e.g., `CompiledGraph`, `Step`, `Feature`)
- **React hooks:** camelCase with `use` prefix (e.g., `useExperiment`, `useTweaks`)
- **React components:** PascalCase (e.g., `SemanticMap`, `TweaksPanel`)

**Functions:**

- **Python:** snake_case (e.g., `run_experiment`, `full_analysis`, `compile_attribution`)
- **JavaScript:** camelCase (e.g., `fireExperiment`, `buildFocal`, `getResults`)
- **Private Python:** Prefix with `_` (e.g., `_run_experiment_sync`, `_umap_lock`)
- **API endpoints:** kebab-case routes (e.g., `/api/experiment/fire`, `/api/chain/status`)

## Where to Add New Code

**New Experiment Feature:**
- Experiment logic: `canon_experiment.py` (add function, follow `run_experiment` pattern)
- Analysis logic: `canon_analysis.py` (add function, follow metric pattern)
- Backend endpoint: `backend/routers/experiment.py` (add route, add schema to `backend/schemas.py`)
- Frontend screen: `frontend/src/screens/NewScreen.jsx` (follow `MapScreen.jsx` structure)

**New Component/Module:**
- Reusable viz: `frontend/src/components/NewViz.jsx` (use CSS modules if needed)
- Reusable hook: `frontend/src/hooks/useNewLogic.js` (follow `useExperiment.js` pattern)
- External API client: New file at root (follow `neuronpedia_client.py` pattern)

**Utilities:**

- **Shared helpers:** `frontend/src/api.js` for HTTP, Python root for lib-level functions
- **Constants:** Top of module (e.g., `INJECTION_MODES` in `canon_experiment.py`)
- **CSS/Design:** `frontend/src/styles.css` (RawBlock design system, use CSS variables)

## Special Directories

**`.planning/codebase/`:**
- Purpose: GSD analysis documents
- Generated: By `/gsd:map-codebase` command
- Committed: Yes (reference docs, not changing frequently)

**`results/`:**
- Purpose: Experiment artifacts (experiment.json, analysis.json, chain JSONs)
- Generated: By backend endpoints (`POST /api/experiment/fire`, `POST /api/chain/focal`)
- Committed: No (ephemeral; cleared between experiments)

**`frontend/dist/`:**
- Purpose: Built React SPA (production bundle)
- Generated: By `npm run build` (Vite)
- Committed: No (rebuilt during deploy)

**`.venv/`:**
- Purpose: Python virtual environment
- Generated: By `python3 -m venv .venv`
- Committed: No

**`frontend/node_modules/`:**
- Purpose: npm dependencies
- Generated: By `npm install`
- Committed: No (use npm ci for reproducibility)

## Build & Dev Setup

**Backend:**
```bash
# Create venv (one time)
python3 -m venv .venv
source .venv/bin/activate

# Install deps
pip install -r requirements.txt

# Run dev server (with auto-reload)
python3 -m uvicorn backend.main:app --port 8000 --reload
```

**Frontend:**
```bash
cd frontend

# Install deps (one time)
npm install

# Dev server (with HMR, /api proxies to backend)
npm run dev        # http://localhost:5173

# Build for production
npm run build      # outputs to frontend/dist/
```

**Local Full Stack:**
- Backend on port 8000
- Frontend on port 5173 (dev) or served from `frontend/dist/` (production)
- Environment: `.env` file with OPENROUTER_API_KEY, NEURONPEDIA_API_KEY
